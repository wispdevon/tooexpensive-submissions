# TooExpensive.dev project submissions

Have a useful alternative to share? [Submit a project for review](https://github.com/wispdevon/tooexpensive-submissions/issues/new?template=project.yml).

This repository is the public review queue for [TooExpensive.dev](https://tooexpensive.dev). A GitHub account is required. Everything in an issue is public: do not include private information, credentials, or customer data.

Include the job your project does, the tool it could replace, developer attribution, a working website or repository, use tags, and pricing/license details. Hosted services are welcome when clearly labeled; a public repository alone does not make a project open source.

## Review process

1. New submissions receive `needs-review`.
2. Wisp checks the links, description, developer attribution, use tags, current pricing, and license. A maintainer may request more information with `needs-info`.
3. Accepted projects receive `approved`; unsuitable or duplicate entries receive `declined` with an explanation.
4. Approval does not automatically publish anything. Wisp adds the reviewed entry to the website's project data and deploys it, then closes the issue as completed.

Listing is not a guarantee of feature parity, cost savings, or endorsement. Keep comparisons specific and avoid unsupported claims about other products. Submitting your own project or a recommendation is welcome; disclose which it is.
